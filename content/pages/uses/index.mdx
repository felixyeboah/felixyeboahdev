## Uses

I don't get asked about my work environment so often, but just in case if you want to know, here are the tools, devices and services I use to get things done. These are not the best ones, but I personally feel these very comfortable. I consider this as a checklist too.

## Services

- Music from [Spotify](https://spotify.com) and [Apple Music](https://music.apple.com)
- I mostly spend my days on Youtube watching tutorials and other relevant videos
- [Google Drive](https://drive.google.com) for all my files
- All my studies on [Udemy](https://udemy.com) and [Frontend Masters](https://frontendmasters.com)
- [Fly.io](https://fly.io) and [Vercel](https://vercel.com) - An amazing hosting platform
- [Cloudinary](https://cloudinary.com) - Fantastic image hosting
- [GitHub](https://github.com) - Where I host my code. I also run CI/CD
  pipelines via GitHub Actions.
- I connect with tech communities [Slack](https://slack.com), [Discord](https://discord.com) and [Twitter](https://twitter.com)
- [Namecheap.com](https://namecheap.com) and [Spaceship](https://spaceship.com) - Where I buy all my domain names.
- I listen to my podcasts on [Apple PodCasts](https://podcasts.apple.com)
- News feeds on [Medium](https://medium.com), [Dev.to](https://dev.to) and [Reddit](https://reddit.com)
- My package Managers are [Yarn](https://yarnpkg.com) and [Pipenv](https://pipenv.pypa.io/en/latest/)
- [Setapp](https://setapp.com) - A fantastic app subscription service for Mac

## Tech

- [React](https://reactjs.org/) - The most widely used frontend framework in the
  world
- [Remix](https://remix.run) - The best framework to build a web app and now my favorite react framework
- [NextJS](https://nextjs.org) - A great framework for building React apps
- [Go](https://golang.org/) - My favorite backend language
- [Python](https://python.org) - My favorite scripting language
- [Prisma](https://www.prisma.io/) - A fantastic ORM for Node.js (I use it with
  Postgres/SQLite hosted on Fly.io).
- [TypeScript](https://www.typescriptlang.org/) - I can't imagine building
  JavaScript projects without TypeScript.
- [Testing Library](https://testing-library.com/) - A great testing library for
  anything that interacts with the DOM.
- [Jest](https://jestjs.io/) - A great testing framework.
- [Cypress.io](https://cypress.io) - I use this for E2E testing.
- [MSW](https://mswjs.io/) - Next generation API mocking.
- [Prettier](https://prettier.io/) - I can't imagine life without it.
- [Reach UI](https://reach.tech/) - An accessibility-focused set of easy-to-use
  and easy-to-style components.
- [PostCSS](https://postcss.org/) - I only use these plugins: `tailwindcss`,
  `autoprefixer`, and `postcss-import`
- [TailwindCSS](https://tailwindcss.com/) - A great way to keep my styling
  consistent and stay productive.
- [mdx-bundler](https://github.com/kentcdodds/mdx-bundler) - Compile and bundle
  your MDX files and their dependencies. FAST.
- [Vite](https://vitejs.dev/) - A fast frontend build tool.
- [Chakra-UI](https://chakra-ui.com/) - A great component library for React.

## Editor

- [Pycharm](https://www.jetbrains.com/pycharm/) - My favorite IDE for Python, [Golang](https://golang.org/) & [Webstorm](https://www.jetbrains.com/webstorm/) - My favorite IDE for JavaScript from Jetbrains are my current editor which I switched to in 2020 after years of using Visual Studio Code. I still use VSCode for markdown files and quick edits.
- I'm currently switching between [Firefox Developer](https://www.mozilla.org/en-US/firefox/developer/) and [Microsoft Edge](https://www.microsoft.com/en-us/edge). Currently, I use [Arc](https://arc.io) as my main browser.
- [Dank Mono](https://dank.sh) font by
  [Phil Plückthun](https://twitter.com/_philpl)
- I currently use [Iterm2](https://iterm2.com/) as my terminal with [Oh My Zsh](https://ohmyz.sh/) for my terminal theme and plugins.
